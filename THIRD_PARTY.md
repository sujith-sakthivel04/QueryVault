commercial UI assets or real enterprise dataset are included. The logistics rows
are generated arithmetically by migrations.sql. The QueryVault mark is CSS/text.

React, Vite, AG Grid Community, SQLGlot, FastAPI, python-dotenv, pytest and Vitest
are open-source dependencies. Requests uses Apache-2.0. Psycopg uses LGPL-3.0;
its optional binary distribution includes additional library notices. Preserve
installed package notices and consult each distribution before redistribution.
AG Grid Enterprise is not installed or used. Node dependency licenses are retained
inside their packages; Python metadata is installed in the local virtual environment.

Installed package metadata was checked during final QA: React, React DOM,
AG Grid Community/React, Vite and Vitest declare MIT; TypeScript declares
Apache-2.0. The public source candidate does not redistribute PostgreSQL or
Python/Node package binaries. It includes three buyer-workspace screenshots.
Seller screenshots stay local because they show internal ledger row and quote IDs.

DM Sans and Manrope are loaded through Google Fonts (SIL Open Font License); they
are not bundled. System-font fallbacks render if network access is unavailable.
